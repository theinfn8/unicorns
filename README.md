This is a small projected I created for IT371 Web Design. I went a little overboard and incorporated additional technologies that were unnecessary. The setup ties into an apache server that serves the static content, so there are a few missing parts here. This is the code necessary to build the WAR that runs on a Tomcat server that serves the apache server.
